It buys only confirmed breakouts — broad, accelerating buy inflow pushing the price up near its window high, many distinct buyers, no single wallet dominating — starts small, pyramids into strength only, and exits fast (stop-loss, trailing stop, take-profit, fading flow, one very large single sell, short time limit), because a pump.fun coin's peak is usually followed by a dump.
